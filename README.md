# Mainspring

A 2.5D puzzle platformer made with Godot 4.7. You are Courier Seven, a wind-up mail robot in
the town of Brasswick, frozen at one minute to midnight. Each attempt lasts a few seconds of
spring. **Unwind** and time resets, but the you that was keeps walking: your past loop
becomes an *echo* that repeats exactly what you did. Echoes hold plates down, serve as steps
and run errands while you do something else. Every level delivers a letter, and hidden cogs
unlock pages of the clockmaker's journal.

The story runs in two acts. **One Minute to Midnight** (16 deliveries) ends when the clock
strikes twelve; **New Year** (7 deliveries) picks up the next morning, with the town's bells and
conveyor belts running again.

## Controls

| Action | Keyboard | Gamepad |
| --- | --- | --- |
| Move | ← → or A D | D-pad, left stick |
| Jump | Space, ↑ or W | A |
| Unwind (keep this loop as an echo) | R or Shift | X |
| Undo last echo | Z or U | Y |
| Restart level | Backspace | Back |
| Pause | Esc or P | Start |

Phones get on-screen buttons automatically (Settings → Touch buttons: Auto / On / Off).

## Rules worth knowing

- An echo repeats your inputs from the start of the loop, waiting included, then stands still.
- Echoes are solid on top (you can stand on them), but everyone walks through each other.
- Plates hold doors open (and lifts up) only while something is on them. Plate, door and
  lift colours match.
- Doors never close on someone standing in the doorway.
- A **bell** holds your echoes still for four seconds, even in mid-air, so a jumping echo can
  become a step. It holds only the echoes recorded before whoever rang it, so an echo that rang
  it replays exactly what you did.
- **Belts** carry anyone and anything standing on them. Push a crate along a belt and it goes
  twice as fast; walk against one and you go slowly. A crate on a belt stops against anyone in
  its way.
- The spring doesn't start until your first key press, until you have an echo; from then on
  it starts the moment the loop does, because your echoes are already moving.
- Solving with the fewest echoes earns the level's wax seal.

## Project layout

- `scripts/sim.gd`: the whole puzzle world as a deterministic tile simulation (no rendering).
- `scripts/levels.gd`: maps (ASCII), letters, journal pages, plus a scripted solution per level.
- `scripts/world_view.gd`, `scripts/courier.gd`: the 3D presentation, built from primitives.
- `scripts/game.gd`, `scripts/hud.gd`: loop/echo handling, HUD, pause and delivery card.
- `scripts/ui/`: title screen, level list, letters book, settings.
- `scripts/autoload/`: `Save` (progress, settings, input map), `Sfx`, `Touch`.

## Tools

```sh
tools/v.sh                 # replay every level's solution through the simulation: must say ALL OK
tools/v.sh 6 -t -v         # one level (0-based), with a position trace per input token
python3 tools/gen_audio.py assets/audio   # regenerate all sounds and music
python3 tools/gen_icon.py  # regenerate the icon
tools/web.sh               # export the web build and serve it on http://localhost:4956
tools/itch.sh              # web build zipped for itch.io: build/mainspring-web.zip
```

Debug arguments (after `--`): `--level=N` (1-based), `--auto` / `--auto=cog` (plays the
scripted solution), `--finale` (with `--level`, jump to that act's ending; nothing is saved),
`--touch`, `--menu=levels|book|clean`, `--shot=path.png --frames=N`.

### Making a level

Add an entry to `Levels.ALL` with a unique `id` (saves refer to levels by id, so levels can be
inserted anywhere). Map legend: `#` wall, `S` start, `X` mailbox, `*` cog, `C` crate,
`a`–`e` plates, `A`, `B`, `D`, `E` doors (`C` is the crate), `1`–`5` lifts (raised by plates
`a`–`e`, `rise` sets how far; a lift in the floor row sits flush so crates can be pushed on),
`-` one-way ledge, `^` steam vent (a crate on it smothers it), `@` bell, `>` `<` conveyor belt. A vertical run of one door letter
is a single doorway that never closes on anyone inside it. A level with a cog also needs a
journal `page`. Write a `solution` (and `cog_solution` if it hides a cog) and check it with
`tools/v.sh`. A jump clears 1 tile alone and 2 from a head or a crate. `Levels.ACTS` says
where each act starts; finishing an act's last level plays its ending. A level's `light`
(0 night to 1 day) sets the sky; second-act levels default to day.
